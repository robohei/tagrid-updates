# tagrid-updates

The update feed for **Tagrid**, a macOS audio tag editor.

## ⚠️ Do not delete or rename this repository

`appcast.xml` is served from here at:

```
https://robohei.github.io/tagrid-updates/appcast.xml
```

That address is **compiled into every copy of Tagrid** that has ever been
distributed. It cannot be changed retroactively. If this repository is deleted
or renamed, or if the GitHub account is renamed, **automatic updates break
permanently for every existing installation** — those users would have to find
and download a new copy by hand.

Nothing else here is fragile. The `.dmg` / `.zip` / `.delta` files live in this
repository's [Releases](../../releases) purely for convenience, and can be moved
anywhere at any time by editing the download URLs in `appcast.xml`.

## What is in here

| File | Purpose |
|---|---|
| `appcast.xml` | The list of available versions. Generated by Sparkle's `generate_appcast`, not edited by hand. |
| `.nojekyll` | Tells GitHub Pages to serve the files as-is, without running Jekyll over them. |

The application source lives in a separate, private repository.

## Publishing a release

See `docs/DISTRIBUTION_TODO.md` in the app repository for the full procedure.
In outline: build, package, run `generate_appcast` against the folder of past
zips, then push the regenerated `appcast.xml` here and attach the binaries to a
GitHub Release in this same repository.

The folder of past zips must be kept — without it, `generate_appcast` cannot
build delta updates and every user downloads the full app instead.
