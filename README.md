# tagrid-updates

The update feed for **Tagrid**, a free batch audio tag editor for macOS.

- **Download Tagrid:** https://tagrid.pages.dev/
- **All versions:** [Releases](../../releases)

## ⚠️ Do not delete or rename this repository

`appcast.xml` is served from here at:

    https://robohei.github.io/tagrid-updates/appcast.xml

That address is **compiled into every copy of Tagrid** that has ever been
distributed, and cannot be changed retroactively. If this repository is
deleted or renamed, or if the GitHub account is renamed, **automatic updates
break permanently for every existing installation.**

## What is in here

| File | Purpose |
|---|---|
| `appcast.xml` | The list of available versions, read by the updater inside the app. Generated by Sparkle's `generate_appcast`, not edited by hand. |
| `.nojekyll` | Tells GitHub Pages to serve the files as-is. |

Each release attaches `Tagrid.dmg` (the app itself) and `Tagrid-<version>.zip`
(what the in-app updater downloads — you do not need it).

GitHub also attaches a "Source code" archive to every release automatically.
That is a snapshot of *this* repository — the feed and this README — not the
Tagrid application source, which lives in a separate private repository.
